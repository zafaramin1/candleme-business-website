How to test on iPhone: open each link in Safari, tap Share, then Add to Home Screen (they are named "Test A", "Test B", "Test C"). Turn on Dark Mode (the WebKit bug is most visible in Dark Mode). Force-quit each test app, then open it from the home screen. Repeat about 5 times per app and compare. A small grey "TEST A/B/C" label in the bottom-left corner shows which one you are looking at.
